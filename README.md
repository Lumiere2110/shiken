# 試験 — 過去問CBT

いろいろな試験の過去問を登録して、**CBT方式**（パソコン上で受験する形式）で解けるWebアプリです。

**ジャンル → 試験の種類 → 年度（回）** の順に選んで受験します。

## 使い方

- `index.html` をブラウザで開くだけで動きます（サーバ不要）。
- GitHub Pages を有効にすれば Web 上でも使えます。

### CBTの機能

- 問題一覧パネル（解答済み・未解答・見直しマークが一目でわかる）
- 「後で見直す」マーク、見直し画面
- 制限時間タイマー（時間切れで自動採点）
- **本番モード**（最後にまとめて採点）／**練習モード**（1問ごとに正誤と解説）
- 問題・選択肢のシャッフル
- 採点結果：正答率、合否判定、分野別の成績、全問の解答と解説
- 間違えた問題だけ再挑戦
- 受験履歴（ブラウザに保存、年度一覧に最高点・前回点を表示）
- **復習ノート**（画面右上の「📒 復習ノート」から開く）
  - 採点時に間違えた問題を自動で追加（開始画面のオプションでオフにできます）
  - 受験中・結果画面の「＋ 復習ノートに追加」で、復習したい問題を手動で追加
  - 試験・分野で絞り込み、間違えた回数順などで並べ替え
  - 各問題の正解と解説を表示、メモを書き込める
  - ノートの問題だけをまとめて解く（練習モードなら1問ごとに解説）。試験をまたいで出題できます
  - 不正解回数・連続正解回数を記録し、覚えた問題はノートから外せます

### 解説

解説は次の画面で表示されます。

- 練習モード：「解答を確認」を押した直後
- 結果画面：全問の「解答と解説」
- 復習ノート：各問題を開いたとき

問題全体の解説（`explanation`）に加えて、選択肢ごとの解説（`choiceExplanations`）も書けます。

## 過去問の追加方法

### 1. 問題ファイルを作る

`data/<ジャンル>/<試験>/<年度>.js` を作ります。例: `data/it/fe/r06.js`

```js
registerExam({
  genre: "it",
  exam: "fe",
  year: "r06",
  title: "基本情報技術者試験 令和6年度",
  timeLimit: 90,      // 制限時間（分）。0 で制限なし
  passingRate: 60,    // 合格ライン（%）
  source: "出典を書く",
  questions: [
    {
      category: "基礎理論",           // 分野（結果画面で分野別に集計）
      text: "問題文\n改行もできます",
      code: "擬似コードなど（任意）",
      image: "data/it/fe/img/q1.png", // 図（任意）
      choices: ["選択肢ア", "選択肢イ", "選択肢ウ", "選択肢エ"],
      answer: 1,                       // 正解の番号（0 = ア, 1 = イ, ...）
      explanation: "解説（任意）",
      choiceExplanations: [            // 選択肢ごとの解説（任意。choices と同じ順）
        "アが誤りの理由", "イが正しい理由", "ウが誤りの理由", "エが誤りの理由"
      ]
    },
    {
      text: "複数選択の問題は answer を配列にします",
      choices: ["A", "B", "C", "D"],
      answer: [0, 2]
    }
  ]
});
```

### 2. カタログに登録する

`data/catalog.js` の該当する試験の `years` に1行追加します。

```js
{ id: "r06", label: "令和6年度", file: "data/it/fe/r06.js" }
```

新しいジャンル（例: 語学、数学）や試験の種類も、`catalog.js` に同じ形で追加できます。

```js
{
  id: "lang",
  name: "語学",
  description: "英語・漢字など",
  exams: [
    { id: "eiken2", name: "英検2級", years: [ /* ... */ ] }
  ]
}
```

## 著作権について

同梱している問題は、動作確認用に作成した**オリジナルの練習問題**で、実際の過去問ではありません。
過去問を追加する場合は、各試験の実施団体が定める利用条件を確認し、出典を `source` に記載してください。
