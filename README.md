# 試験 — 過去問CBT

いろいろな試験の過去問を登録して、**CBT方式**（パソコン上で受験する形式）で解けるWebアプリです。

**ジャンル → 試験の種類 → 年度（回）** の順に選んで受験します。

## 使い方

- `index.html` をブラウザで開くだけで動きます（サーバ不要）。
- GitHub Pages を有効にすれば Web 上でも使えます。

### CBTの機能

- 問題は大きめの文字で、画面の少し左寄りに表示。選択肢は文字で並び、右側の「解答」ボタン（ア・イ・ウ…）で答える
- 問題の左下：「問題一覧」（押すと一覧が開き、解答済み・未解答・見直し・チェックが一目でわかる。番号を押すとその問題へ移動）、「電卓」（ドラッグで移動でき、キーボードでも入力できる。移動した位置は次に開いたときも保たれる）
- 問題の右下：「後で見直す」「前へ」「次へ」
- 問題の右上：「チェック」（付けた問題は採点結果に ✔ 印が付き、チェックした問題だけを表示することもできる）
- 画面右上：制限時間タイマー（時間切れで自動採点）、「試験を終了」（未解答・見直し・チェックの数を確認してから採点）
- **本番モード**（最後にまとめて採点）／**練習モード**（1問ごとに正誤と解説）
- 問題・選択肢のシャッフル
- 採点結果：正答率、合否判定、分野別の成績、全問の解答と解説
- 間違えた問題だけ再挑戦。間違えた問題は回ごとにブラウザに記録され（正解すると記録から外れる）、年度の開始画面の「間違えた問題だけ受ける」で後からでも受けられる
- 受験履歴（ブラウザに保存、年度一覧に最高点・前回点を表示）

## 過去問の追加方法

### 1. 問題ファイルを作る

`data/<ジャンル>/<試験>/<年度>.js` を作ります。例: `data/it/fe/r06.js`

```js
registerExam({
  genre: "it",
  exam: "fe",
  year: "r06",
  title: "基本情報技術者試験 令和6年度",
  timeLimit: 90,      // 制限時間（分）。0 で制限なし
  passingRate: 60,    // 合格ライン（%）
  source: "出典を書く",
  questions: [
    {
      category: "基礎理論",           // 分野（結果画面で分野別に集計）
      text: "問題文\n改行もできます",
      code: "擬似コードなど（任意）",
      image: "data/it/fe/img/q1.png", // 図（任意）
      choices: ["選択肢ア", "選択肢イ", "選択肢ウ", "選択肢エ"],
      answer: 1,                       // 正解の番号（0 = ア, 1 = イ, ...）
      explanation: "解説（任意）"
    },
    {
      text: "複数選択の問題は answer を配列にします",
      choices: ["A", "B", "C", "D"],
      answer: [0, 2]
    }
  ]
});
```

### 2. カタログに登録する

`data/catalog.js` の該当する試験の `years` に1行追加します。

```js
{ id: "r06", label: "令和6年度", file: "data/it/fe/r06.js" }
```

新しいジャンル（例: 語学、数学）や試験の種類も、`catalog.js` に同じ形で追加できます。

```js
{
  id: "lang",
  name: "語学",
  description: "英語・漢字など",
  exams: [
    { id: "eiken2", name: "英検2級", years: [ /* ... */ ] }
  ]
}
```

## 記述式（午後）の採点

応用情報の午後のような記述式問題は、IPA の「解答例・解答の要点」と「採点講評」を基準に採点します。**料金のかかる API は使いません。** 解答を終えたら、次のどちらかを選びます。

- **A. Claude で採点（コピペ方式・おすすめ）**：「採点用の文をコピー」を押して Claude（claude.ai やアプリ）に貼り付け、返ってきた返事を貼り戻すと点数が出ます。採点基準は厳しめです（要点が全てそろって満点、一部だけなら配点の半分、論点ずれ・本文と矛盾・一般論だけなら 0 点、迷ったら低い方）。
- **B. ブラウザ内 AI で簡易チェック（オフライン・参考程度）**：WebLLM で小さな AI（Qwen3.5 4B / 9B）を PC の中で動かし、設問ごとの要点に触れているかを はい／いいえ で判定して点数を出します（全部はい→満点、一部→半分、なし→0 点）。WebGPU 対応ブラウザ（Chrome / Edge など）とグラフィックボードが必要で、初回はモデルのダウンロード（約 3〜6GB）があります。解答はネットに送られません。

どちらの方法でも、選択式・空欄・字数超過（字数は空白・改行を除いた文字数）・解答例と完全一致はサイト側で採点します。IPA は午後の配点を公表していないため、配点は本サイトで設定したものです。AI の判定は参考値として使ってください。

記述式の問題データは `format: "essay"` とし、問ごとに `body`（問題文・図）と `parts`（設問、`type: "choice"` か `"text"`、`maxChars`、`answer`＝IPA 解答例、`points`）を書きます。記述式の設問には、簡易チェック用に `checks`（IPA 解答例の要点を 2〜3 個に分けたもの。本サイトで作成）を付けられます。付けない場合は解答例そのものを 1 つの要点として判定します。例は `data/it/ap/r07a_pm.js`。

## 収録している試験

| ジャンル | 試験 | 年度 |
|---|---|---|
| 情報系 | ITパスポート試験 | 令和8年度・令和7年度・令和6年度 公開問題（各100問） |
| 情報系 | 基本情報技術者試験 | 令和8年度・令和7年度 公開問題 科目A（各20問）・科目B（各6問） |
| 情報系 | 応用情報技術者試験 | 令和7年度・令和6年度 秋期・春期 午前（各80問）・午後（記述式、各11問） |

表は `table`（行の配列）または `tables`（`[{ caption, rows }]`）で書けます。セルの先頭に `_` を付けると実線の下線（主キー）、`~` を付けると破線の下線（外部キー）になります。

## 出典・著作権について

- 情報処理技術者試験（ITパスポート・基本情報・応用情報）の問題文・図・正解は、独立行政法人情報処理推進機構（IPA）の公開問題・解答例によります。解説は本リポジトリで作成したもので、IPA によるものではありません。
- 過去問を追加する場合は、各試験の実施団体が定める利用条件を確認し、出典を `source` に記載してください。
